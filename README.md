# 耐心资本与企业跨省投资 · 实证进度

这个仓库放给导师看的进度说明。结果表不放在这里，直接发给老师。每轮实证做完，新增一个 `rounds/日期/` 文件夹，并在 `CHANGELOG.md` 记几行。数据留在本地，按授权不上传；生成表格的代码放在 `code/`。

## 老师怎么用

- **直接看**。打开 [`answers.md`](answers.md)，分三部分回复了 10 月 5 日的意见，第二部分逐条说明哪些结果能支撑老师的判断、哪些不能。表号对应另外发给老师的新表。
- **用 Gemini**。在 gemini.google.com 对话框点“添加文件”，选“导入代码”，粘贴本仓库链接 https://github.com/lican1213/patient-capital-progress ，导入后问“按 answers.md 告诉我 10 月 5 日的意见现在的回复”。仓库更新后要重新导入一次。
- **用 ChatGPT**。把 `answers.md` 和另外发给老师的新表 PDF 一起上传到对话里再提问。也可以把纯文本链接 https://raw.githubusercontent.com/lican1213/patient-capital-progress/main/answers.md 贴进对话。
